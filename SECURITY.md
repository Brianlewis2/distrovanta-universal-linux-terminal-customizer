# Security

DISTROVANTA does not collect personal data or send data to external servers.

## Practices

- No eval of user input.
- No destructive commands without backup.
- Managed blocks marked with comments for safe removal.
- Input validation for names/colors.
- Path safety checks.
- No root required for common personalization.
