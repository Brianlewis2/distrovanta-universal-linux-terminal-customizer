# Usage

Run `./distrovanta.sh`. Navigate with numbers. Each option shows description and compatibility.

## Prompt customization

Sets visual name/env name, color, separator, directory display. Applied to ~/.bashrc inside a managed block. Never changes real user or hostname.

## Panel

Creates a startup panel configured via title/subtitle/welcome/color.

## Backup & Restore

Backups recorded in `~/.distrovanta/backups/manifest.log`. Restore strips managed blocks or restores full file from backup.
