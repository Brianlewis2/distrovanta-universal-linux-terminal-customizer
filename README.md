# DISTROVANTA

Universal Linux Terminal Customizer

Independent project by **Brian Lewis** (Full Stack Developer • AI Engineer).
Discrete partnership: **BRJ Dev**.

## Overview

DISTROVANTA is a modular, multi-distribution Linux terminal customization tool.
It provides a centralized interface to customize prompts, panels, banners, colors,
welcome messages and system information, with safe backup and restore.

It is NOT a security, intrusion or vulnerability tool. Its purpose is exclusively
terminal environment personalization.

## Features

- Interactive numeric menu
- Dynamic banner centering by terminal width
- Distribution and shell detection
- Visual prompt customization (never changes real user/hostname)
- Custom startup panels
- Themes & colors
- Custom banners
- Welcome messages
- System information display
- Configuration manager
- Backup manager
- Restore (safe, block-based + full from backup)
- About developer / social media / about tool
